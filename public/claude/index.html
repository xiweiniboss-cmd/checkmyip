Claude 环境检测

看看访问 Claude 时实际用的是哪个出口、分流有没有生效、出口地区是否受支持，以及浏览器暴露了多少「中国用户」特征。

浏览器环境只在本地检测。 本页不会主动把国内出口 IP 发给本站；Claude 出口 IP 会经本站 /api/ip（以及本站用的归属地接口，如 ip.sb、ipwho.is 和 DNS 反查）查询类型与纯净度， 不写入数据库、不写日志，查询结果仅按 IP 在 Cloudflare 边缘短时缓存（最多 6 小时）； 为了检测，浏览器会访问 claude.ai、1.1.1.1、my.ip.cn 和 STUN 服务器（stun.cloudflare.com、stun.miwifi.com）。 页面加载时也会像首页一样查询你访问本站用的 IP：只读取「本站观测」计数，本页不上报指纹、不写入 D1。

这一项怎么看？网页可以读到你的时区、语言和已安装字体，这些都不是 IP 能掩盖的。分数越高，说明浏览器越像在中国大陆使用。 它只是「可被读取的特征」，目前没有公开证据表明 claude.ai 会仅凭这些封号。

关于 Claude Code：有说法称 Claude Code 在设置了第三方 ANTHROPIC_BASE_URL 时会把本机时区等信息编码进提示词，未经证实，本站没有验证过，这里的分数只是估计。

为什么中文字体权重很低：macOS 自带苹方（PingFang SC），Windows 自带微软雅黑，很多 Linux 发行版和安卓自带 Noto CJK，海外用户也会命中，误报率很高。
